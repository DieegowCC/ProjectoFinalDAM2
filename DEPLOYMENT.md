# SETT Deployment Guide

## Prerequisites

Before building the installer, ensure you have:

1. **.NET 9 SDK** - For publishing the API
2. **.NET 8 SDK** - For publishing the Agent
3. **Node.js 20+** - For building the frontend
4. **InnoSetup 6+** - For creating the installer

## Quick Start

### Step 1: Start PostgreSQL

```bash
cd backend
docker compose up -d
```

### Step 2: Build Everything

Run the publish script:

```bash
cd scripts
publish.bat
```

This will:
1. Build Next.js frontend as static export (`frontend/out/`)
2. Copy frontend to API's wwwroot (`backend/settAPI/wwwroot/`)
3. Publish API to `publish/api/`
4. Publish Agent to `publish/agent/`

### Step 3: Create Installer

1. Open `installer/sett.iss` in InnoSetup
2. Press Ctrl+F9 to compile
3. The installer will be created at `publish/installer/SETT-Setup.exe`

## Manual Steps (If Needed)

### Building Frontend Manually

```bash
cd frontend
npm run build
# Output goes to frontend/out/
```

### Publishing API Manually

```bash
cd backend/settAPI
dotnet publish -c Release --self-contained true -r win-x64 -o ../../publish/api
```

### Publishing Agent Manually

```bash
cd desktop-service/settAGENT
dotnet publish -c Release --self-contained true -r win-x64 -o ../../publish/agent
```

### Copying Frontend to API

```bash
# After building frontend
xcopy /E /Y frontend\out\* backend\settAPI\wwwroot\
```

## Post-Installation

### For Service Installation:
- SETT API runs as `SETTAPI` Windows Service (port 5263)
- SETT Agent runs as `SETTAGENT` Windows Service
- Dashboard available at: http://localhost:5263

### For Portable Installation:
- Run `settAPI.exe` to start the API
- Run `settAGENT.exe` to start the Agent
- Dashboard available at: http://localhost:5263

## Troubleshooting

### PostgreSQL Connection Error
Ensure Docker is running: `docker ps`

### Port 5263 Already in Use
Stop any existing SETT services: `sc stop SETTAPI`

### Agent Not Connecting
Check that the Worker exists in the database with matching hostname.
Run `echo %COMPUTERNAME%` on the worker machine and create a matching Worker entry via the dashboard.
